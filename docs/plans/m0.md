# Grace M0 (Foundation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (native: one session builds it, then one whole-branch review). Steps use checkbox (`- [x]`) syntax. Tick boxes as you go: after a compaction, this file is the source of truth for where M0 stands.

**Goal:** An installable Grace desktop app that finds the user's Claude Code sessions and lists them, with an interactive 3D Grace guiding onboarding. Plus `grace doctor`, `grace sessions` and `grace serve`, CI, and draft-release installers for Windows, macOS and Linux.

**Architecture:** A Rust workspace.
- `grace-core` holds the event model, redaction, the Claude Code adapter, the SQLite store, the scanner, tool discovery, config, and an axum API behind the `server` feature.
- `grace-cli` is the `grace` binary.
- `app/src-tauri` is the Tauri 2 shell. It runs the same API in-process and shows the React UI from `ui/`, which `grace serve` can also serve to a browser.
- Grace's 3D model is built by a Blender script and drawn with three.js.

**Tech Stack:**
- Rust 1.100 (edition 2024): serde_json, rusqlite (bundled), regex, clap, toml_edit, axum + tokio, rust-embed, getrandom, Tauri 2.
- UI: React, TypeScript (strict), Vite, Tailwind CSS v4, Radix (shadcn/ui pattern), TanStack Query, wouter, three.
- Tests: cargo test + insta, Vitest, Playwright.
- Blender 5.3 (dev only).

**Spec:** `docs/GRACE_SPEC.md` (§4, §6, §7, §11, §12, §13), `docs/DESIGN.md` (§1–3, §5, §6), decisions in `docs/adr/0001-stack-mascot-free.md`.

## Global Constraints

- **Budgets (spec §11):**
  - installer ≤ 20 MB per OS; `grace` CLI ≤ 15 MB;
  - app idle ≤ 60 MB RAM, window open ≤ 250 MB (raised from 200 MB on 2026-11-27 so live 3D Grace fits);
  - cold start ≤ 1 s to first screen; UI navigation ≤ 100 ms;
  - 100 MB transcript parsed in ≤ 10 s;
  - each mascot image ≤ 100 KB; mascot model ≤ 300 KB.
- **R16 free only:** permissive licenses only (MIT, Apache-2.0, BSD, ISC, Zlib, OFL, Unicode, CC0; MPL-2.0 unmodified). No paid services.
- **R6:** use only the dependencies approved in the M0 plan (listed per task). Ask before adding anything else.
- **R7:** no runtime network calls except the Ollama ping on localhost.
- **R8:** never open credential files (`auth.json`, `.credentials.json`, `oauth_creds.json`, `google_accounts.json`, `.env*`). Redact before anything is stored or shown.
- **R9:** fixtures are tiny and synthetic. Never commit real transcripts.
- **R11:** every event keeps its file, line and turn.
- **Platforms:** Windows, macOS, Linux. CRLF-safe. Paths with spaces, `&` and non-ASCII work (`C:\Users\Test User\Projects\Maple & Moss`).
- **UI:**
  - copy follows DESIGN §4: plain words, numbers over adjectives, no blame;
  - all strings live in `ui/src/strings/en.ts`;
  - WCAG 2.2 AA;
  - tokens exactly as DESIGN §6.
- **Checks:** `cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`, then `pnpm -C ui lint && pnpm -C ui test`.
- **Dev machine (7.7 GB RAM):** `CARGO_BUILD_JOBS=4`. Never run Blender during a cargo build.

## Review Focus

1. **A transcript still being written** (its last line has no newline yet): parsing stops before that line, and the next scan resumes exactly there, with no duplicate or lost events. Test: Task 2 `incremental_parse_resumes_without_duplicates`.
2. **Secrets in transcripts** (an API key in a Bash command, the user's email in `session_context`): never stored or shown unredacted. Tests: Task 2 `redacts_secrets_on_ingest`, plus the Task 1 redaction tests.
3. **Paths with spaces, `&` and non-ASCII:** discovered, stored, shown and used as project names correctly. Test: Task 3 `paths_with_spaces_roundtrip`.
4. **Files that shrink, vanish or get replaced between scans:** the session resets or is removed, with no stale events and no crash. Tests: Task 3 `truncated_file_resets_session`, `removed_file_removes_session`.
5. **Garbage lines and future formats** (invalid JSON, non-UTF-8 bytes, unknown entry types): skipped or logged as drift, never fatal. Tests: Task 2 `survives_garbage_lines`, `parses_basic_fixture` (unknown type).

**Rules the tests pin:**
- **Discovery:** only `<root>/<project>/<id>.jsonl` (subagent files under `<id>/subagents/` come later), newest first.
- **Reading:**
  - start from `state.offset`;
  - only lines ending in `\n` count;
  - decode as lossy UTF-8;
  - a line that isn't JSON → `bad_lines += 1`.
- **Mapping:**
  - follows the table in the M0 plan (repeated in spec §7.6);
  - a `SessionStart` boundary comes before the first event;
  - summaries are redacted, then cut to 160 chars.
- **Turn:** `turnPosition.promptIndex + 1`; otherwise count human prompts.
- **Title:** latest `custom-title`, else the `summary` entry, else the first prompt (80 chars).
- **Model switch:** the assistant's `message.model` changes. Ignore `<synthetic>` and sidechains.
- **Unknown entries:** known-but-ignored entries count in `stats.ignored`. Anything else becomes an `Unknown` event and increments `stats.unknown[label]`.
